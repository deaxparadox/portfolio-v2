# Module Language

Pages do not own UI.

Modules own UI.

Every module must answer exactly one question.

Example

Featured Module

↓

What should I explore first?

Experience Module

↓

Where has this engineer solved problems?

Engineering Module

↓

How does this engineer think?

Resume Module

↓

Need the ATS version?

...

Modules are composable.

Pages arrange modules.

Modules never assume where they are rendered.
