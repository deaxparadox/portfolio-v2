# UX Philosophy

This application should feel like entering an engineer's workspace.

Not navigating a marketing website.

## Principles

- Workspace over webpages.
- Progressive disclosure.
- One question per module.
- Navigation should disappear into the experience.
- Every interaction has purpose.
- Motion improves orientation.
- Avoid decorative animations.
