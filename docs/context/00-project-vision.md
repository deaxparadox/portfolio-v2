## Philosophy

Portfolio V2 is not a portfolio website.

It is an engineering workspace.

The objective is not to show every project or technology.

The objective is to demonstrate engineering thinking.

Visitors should leave understanding:

- How problems are approached.
- How systems are designed.
- How engineering decisions are made.
- How trade-offs are evaluated.
