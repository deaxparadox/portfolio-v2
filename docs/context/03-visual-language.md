# Visual Language

This document defines how the interface should feel.

Not implementation.

Not CSS.

## Principles

Premium over flashy.

Restrained motion.

Whitespace communicates confidence.

Borders define containers.

Shadows are subtle.

Animation explains movement.

Skeletons are mandatory.

Hover interactions should communicate affordance rather than entertainment.
